01 · Overview

What this project solves

Three critical retail challenges — tackled with a full-stack data pipeline from raw CSV to executive dashboard.

🔄

Automated Data Integration

Python ETL pipeline to clean, transform, and load raw transactional data into a structured MySQL database — zero manual intervention.

🎯

Customer Segmentation

Classify all 3,900 customers into New, Returning, and Loyal tiers using purchase history. Identify the most commercially valuable demographics.

💰

Revenue Optimization

Pinpoint the highest-value product categories, age groups, and discount strategies to maximize revenue per customer.

📈

Executive Reporting

Interactive Power BI dashboard with filters by subscription status, gender, category, and shipping type — built for non-technical stakeholders.

03 · Workflow

How the pipeline flows

From raw CSV to boardroom-ready insights in four stages.

01

Data Cleaning & Feature Engineering (Python)

Imputed 37 missing Review Rating values using category-wise median. Engineered an age_group column via quartile binning (Young Adult → Senior). Mapped purchase frequency text to numeric day values and removed a confirmed-redundant duplicate column.

PandasMedian ImputationQuartile BinningFeature Engineering
02

Database Loading (Python → MySQL)

Loaded the cleaned dataset into a MySQL database using SQLAlchemy, structuring the data for relational querying and business analysis.

SQLAlchemyMySQLRelational DB

Business Querying (SQL)

10 targeted SQL queries simulating real analyst tasks: gender revenue split, top-rated products, discount analysis, subscription comparison, customer segmentation, top products per category, shipping impact, and age-group revenue.
